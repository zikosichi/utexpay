# Dashboard stack — second-section alternative

**04 Dashboard stack** is the default on the main landing page, including its initial server render. Open `/#banking` to see it. Four small numbered controls sit at the section's right edge; names appear on hover or keyboard focus. The switcher stays available across all four versions, and `?personal=phone`, `?personal=dashboard` or `?personal=concept` opens a specific alternative. `/section-stack#banking` opens the same section with Dashboard stack selected initially. It is also option 04 in `/section-options?direction=dashboard-stack`.

Reference: [UTEX, node 4815:7466](https://www.figma.com/design/HCaWhMISKtMkyK6o9Euw5d/UTEX?node-id=4815-7466).

Bank uses the user's unmodified 1840 × 1586 transparent `Frame 137.png`, saved as `public/dashboardstack/bank-window.png`. Get paid uses the user's unmodified 1865 × 1666 transparent `Frame 139.png`, saved as `public/dashboardstack/paid-window.png`. Move uses the user's unmodified 1863 × 1620 transparent `Frame 140.png`, saved as `public/dashboardstack/move-window.png`. The surrounding stacked windows are HTML panels with a 58% dark background fill, gradient borders and a live 28px backdrop blur. The border has a restrained upper highlight that fades to a visible bottom edge, with softer highlights on the rear windows. The heading, tabs and stack have larger responsive gaps: 72px / 64px on desktop, 56px / 56px on tablet and 48px / 40px on mobile. The dark fill sits behind the dashboard images, which render at full brightness. The dashboard images are inset within the window on desktop and focus on their main workspaces on mobile. The original full-section Figma export remains in `bank-dashboard.png` as a reference; the SVG assets also come from that node. `ambient-soft.png` is the user's supplied 1936 × 1181 transparent `image 147.png`, displayed behind the frames with a fade along all four edges. The stack, feature navigation and versions 01–03 share the 1280px maximum width and responsive gutters from `banking-container.css`. The page, section and hero's bottom gradient share the `--page-background` color, `#0D0D0F`. The product screens are illustrations; the tabs above the windows control this section.

The “Banking & payments” introduction and globe section use the shared `SectionHeading` component and typography. The version switcher takes no layout space, and a responsive 96–180px gap separates the banking and globe sections.

The Bank / Move / Get paid tabs sit between the section heading and the stacked windows. The active gold line fills over eight seconds, then advances Bank → Move → Get paid → Bank. Clicking any tab brings its frame forward and restarts its progress. A small pause/play control lets the visitor stop or resume the sequence. Progress pauses while the section is out of view or the browser tab is hidden. Keyboard focus stops automatic cycling until the visitor resumes it. Arrow keys wrap between tabs; Home and End select the first and last. Inactive panels are inert and hidden from assistive technology. Reduced motion disables automatic cycling and progress animation, and removes transitions. On mobile the dashboard focuses on its main workspace, with the active description below the three tabs.

The project’s Forge documentation server was unavailable, so the existing component, route and `.stories.json` conventions were followed.
